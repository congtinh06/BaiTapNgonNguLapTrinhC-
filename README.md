Repository lưu trữ các bài thực hành (Lab) của môn **Ngôn ngữ lập trình C#**. Mỗi Lab nằm trong một thư mục riêng, được commit và đẩy lên theo từng bài.

## Cách chạy

1. Clone repository:
   ```
   git clone https://github.com/congtinh06/BaiTapNgonNguLapTrinhC-.git
   ```
2. Mở thư mục Lab cần xem, mở file `.sln` bằng **Visual Studio**.
3. Nhấn **F5** (hoặc **Ctrl + F5**) để chạy chương trình.
